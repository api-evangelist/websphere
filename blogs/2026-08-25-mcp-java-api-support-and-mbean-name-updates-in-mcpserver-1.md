This beta release updates mcpServer-1.0 to use the MCP Java API ( org.mcpjava ), improves MCP metrics MBean naming, and fixes the MCP endpoint URL log message. Open Liberty 26.0.0.9-beta is targeted at application developers building MCP-enabled Liberty applications. The Open Liberty 26.0.0.9-beta includes the following beta features (along with all GA features ): MCP Java API support in mcpServer-1.0 MCP metrics: MBean names now use individual JMX ObjectName keys See also previous Open Liberty beta blog posts .
